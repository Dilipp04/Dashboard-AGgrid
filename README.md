# Employee Dashboard – AG Grid + React + TypeScript

A modern employee management dashboard built using React, TypeScript, and AG Grid.

## 🚀 Features

- ⚡ AG Grid Data Table
- 👤 Profile Picture with Employee Name
- 🏷️ Department Badge with Icons & Colors
- 🔍 Sorting & Filtering
- 📱 Responsive Design
- 🧩 TypeScript Support
- 🎨 Modern UI

---

## 🛠️ Tech Stack

- React
- TypeScript
- AG Grid
